# Tech stack
- C99 bare-metal firmware, WCH CH32V003F4U6 (RV32EC, 24 MHz native HSI, 16 KB Flash, 2 KB RAM).
- PlatformIO: platform=ch32v (Community-PIO-CH32V), board=genericCH32V003F4U6, framework=noneos-sdk (WCH SDK, not ch32v003fun).
- Environments in platformio.ini:
  - `Proteus32`: default (DAC7571 @ 0x4C, standard AUX LEDs)
  - `Proteus32-RGB`: -DUSE_IND_RGB=1 (PC7=R, PC4=G, PC6=B)
  - `Proteus32-MCP4725`: -DUSE_DAC_MCP4725=1 (MCP4725 @ 0x60)
  - `Proteus32-RGB-MCP4725`: -DUSE_IND_RGB=1 -DUSE_DAC_MCP4725=1
  - `mcp4725-init`: utility firmware to flash 0 V into MCP4725 EEPROM
- Compiler optimization: `-Oz` placed in `build_src_flags`, NOT `build_flags` (the ch32v platform appends `-Os` to CCFLAGS after build_flags; build_src_flags is applied later during library cloning, so -Oz wins).
- Linker: custom Link.ld; `-Wl,--defsym=FLASH_SIZE=16128`, `-Wl,--defsym=RAM_SIZE=2048`; `board_upload.maximum_size=16128`.
- Flash layout: user code `0x08000000..0x08003F00` (max 16128 B), WL_FLASH ring `0x08003F00..0x08004000` (256 B, never overwritten by flasher), bootloader in separate 1920 B flash @ 0x00000000.
- Data storage: WL_FLASH v2.4.0 via `lib_deps` tag `#v2.4.0` (remote git pin, no local vendoring in `libs/`). Flags: `-DWL_OB_ENABLE -DWL_FORMAT_VERSION=4 -DWL_RECORD_SIZE=16 -DWL_CRC_BITS=16`. Option Bytes overlay via `include/ob.h` over `wl_ob_*`.
- PC flasher tool: `proteus32_3.py` (protocol rev 2 / v2.1, pairs ONLY with bootloader rev 2). Pytest vectors in `test/test_protocol_v2.py`.
- Serena language server: cpp (clangd). Works with `compile_commands.json` (generated by `python tools/gen_compile_db.py`) + `.clangd` at root. Always generate DB for a single env (default Proteus32) to prevent `-DUSE_IND_RGB=1` define leaks.
