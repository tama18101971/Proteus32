# Plan: Fix Compilation Errors

## Root Cause
Проект прошёл через рефакторинг: `pi_reg` заменён на `thermal_limiter` с новым API. Файлы `limiters.c` и `main.c` были обновлены только частично — они до сих пор используют старые сигнатуры функций и несуществующие поля структур.

## Ошибки (9 штук)

### 1. `limiters.c:29` — `ThermalLimiter_Init` вызывается с 2 аргументами
- **Было:** `ThermalLimiter_Init(&state, &config);`
- **Нужно:** `ThermalLimiter_Init(&state);` (новый API принимает 1 аргумент)

### 2. `limiters.c:44` — `ThermalLimiter_Update` вызывается с 4 аргументами в неверном порядке
- **Было:** `ThermalLimiter_Update(&state, &config, raw_temperature_adc, step_user);`
- **Нужно:** `ThermalLimiter_Update(&config, &state, raw_temperature_adc, T_SET, step_user);` (5 аргументов, config первый)

### 3. `limiters.c:12-13` + `limiters.h:16-17` — `static` vs `extern` конфликт
- `state` и `config` объявлены `static` в `.c`, но `extern` в `.h`
- **Решение:** убрать `extern` из `limiters.h` (main.c не должен напрямую обращаться к `config`/`state`)

### 4. `main.c:56-57` — Обращение к несуществующим полям `config`
- `config.temp_setpoint`, `config.Kp`, `config.Ki`, `config.max_limit` — не существуют в новом `ThermalLimiterConfig_t`
- **Решение:** заменить на `T_SET`, `config.kp_left_shift`, `config.ki_left_shift`, `config.ki_decimation_shift`

### 5. `main.c:93` — `T_SET` не виден в `main.c`
- Макрос `#define T_SET 700u` определён в `limiters.c`, не в заголовке
- **Решение:** вынести `T_SET` в `limiters.h` (или в `thermal_limiter.h`)

### 6. `main.c:153` — `config.temp_setpoint` не существует
- **Решение:** заменить на `T_SET`

### 7. `main.c:158` — `state.p_term_out` не существует
- Нового поля `p_term_out` нет в `ThermalLimiterState_t`
- **Решение:** убрать из отладочного вывода или заменить на `limiter`

### 8. `limiters.h:17` — `config` объявлен без `const`
- Определение: `static const ThermalLimiterConfig_t config`
- Объявление: `extern ThermalLimiterConfig_t config` (без `const`)
- **Решение:** добавить `const` в объявление (или сделать `config` доступным через геттер)

### 9. `thermal_limiter.c:25` — Лишний `#include <stdio.h>`
- На CH32V003 с 16KB Flash это может увеличить размер бинарника
- **Решение:** удалить

## Файлы для изменения

1. **`include/limiters.h`** — убрать `extern state/config`, добавить `T_SET`, добавить `const` для config если нужен extern
2. **`src/limiters.c`** — исправить вызовы `ThermalLimiter_Init` и `ThermalLimiter_Update`
3. **`src/main.c`** — исправить обращения к `config.*` и `state.*`, убрать `state.p_term_out`
4. **`src/thermal_limiter.c`** — удалить `#include <stdio.h>`
