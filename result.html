Битовые поля функции handle_aux()

Проект Proteus003 для микроконтроллера CH32V003 (RISC-V). Управление вспомогательными LED-индикаторами.

1. Команда AUX_Cmd_u (32 бита)

Основная структура, определяющая параметры моргания LED.

Режим: aux (управление LED)

ПолеБитыТипДиапазонОписание
device0..23 bit0b000..0b111Каким LED управляем: RED=001, GRN=010, HBL=100
cycle31 bit0/10 = зациклено, 1 = без цикла
count4..74 bit0..15Количество повторов. 0 = бесконечный цикл
duration08..169 bit0..511Длительность 1-го полупериода (в ×15мс, т.к. handle_aux() вызывается каждые 15мс)
duration117..259 bit0..511Длительность 2-го полупериода (в ×15мс)
brightness026..283 bit0..7Яркость 1-го полупериода: 0=выкл, 1=ярко, 2=слабо
brightness129..313 bit0..7Яркость 2-го полупериода

Режим: cmd (команда обработчика массива)

ПолеБитыТипДиапазонОписание
command0..12 bit0..30=AC_STOP, 1=AC_REP_ATSTART, 2=AC_REP_ATSTEPS
steps2..43 bit0..7Шаг зацикливания (отступ от начала массива)
is_cmd5..3127 bit==0Если все 27 бит == 0, это команда обработчика
Важно: Определение типа команды — по полю is_cmd. Если is_cmd == 0, это системная команда, иначе — параметры LED.

2. Контрольная структура AUX_Ctr_t (32 бита)

Внутреннее состояние каждого LED-канала (красный/зелёный).

ПолеБитыТипДиапазонОписание

period1..33 bit0..40=PER_INIT, 1=PER_FIRST, 2=PER_SECOND, 3=PER_END, 4=PER_NEXT
current_brightness4..63 bit0..7Текущая яркость (для сравнения)
work_duration7..159 bit0..511Оставшаяся длительность текущего полупериода
idmode16..172 bit0..3Режим индикации: OTHER=0, BEACON=1, VWARNING=2, STROBE=3
arr_index18..214 bit0..15Текущий индекс в массиве команд
work_count22..254 bit0..15Оставшееся количество повторов
reserved26..316 bit—Резерв

3. Примеры кодирования команд

3.1 INFO_RED — информационное моргание красным

// 0b00000000000000010001010100010001
//   [reserved]   [bright1=010] [bright0=010] [dur1=000000101] [dur0=000000001] [count=0001] [cycle=0] [device=001]
// device=001 (RED), cycle=0, count=1, dur0=1, dur1=5, bright0=2, bright1=2

Результат: 1 повторение: 1 тик ЯРКО → 5 тиков ЯРКО (моргание 2Hz)

3.2 INFO_GRN — информационное моргание зелёным

// 0b00000000000000010100010000100010
// device=010 (GRN), cycle=0, count=1, dur0=2, dur1=0, bright0=2, bright1=2

Результат: 1 повтор: 2 тика ВКЛ → 0 тиков ВКЛ

3.3 SHORT_BLINK — короткое моргание

// 0b00000000000000010000000000010001
// device=001 (RED), cycle=0, count=1, dur0=1, dur1=0, bright0=1, bright1=0

Результат: 1 повтор: 1 тик ЯРКО → 0 тиков ВЫКЛ

3.4 Beacon (вспышка) — программируемый

// start_aux_beacon() формирует:
// cmd = 0b00000000000000010000000100001000 | beacon_type | ((beacon_mode+7) << 12)
//
// beacon_type = 0..7 (биты 0..2 = тип beacon)
// beacon_mode = 0..7 (биты 12..14 = режим моргания + 7)
// device = 001 (RED), cycle=0, count=0 (бесконечно), dur0=8, dur1=0

4. Формула вычисления

Для формирования 32-битного кода команды:

cmd = device | (cycle << 3) | (count << 4) | (duration0 << 8) | (duration1 << 17) | (brightness0 << 26) | (brightness1 << 29)
Совет: Используйте битовые маски для установки/сброса бит:
cmd |= (1 << 3); — установить cycle=1
cmd &= ~(1 << 3); — сбросить cycle=0

5. Массивы команд (буферы)

Команды хранятся в массивах buf_red[] и buf_grn[]. Каждый элемент — 32-битная команда.

МассивРазмерНазначение
buf_red[5]5 элементовКоманды для красного LED (SOS-паттерн и другие)
buf_grn[3]3 элементаКоманды для зелёного LED

Обработчик handle_aux_array() последовательно выполняет команды из массива, начиная с индекса arr_index.

7. Диаграмма состояний AUX_Ctr_t.period

┌─────────────┐
│  PER_INIT   │ ← Начальное состояние
│   (0)       │
└──────┬──────┘
       │ загружаем duration0
       ▼
┌─────────────┐
│  PER_FIRST  │ ← 1-й полупериод
│   (1)       │   brightness0, duration0
└──────┬──────┘
       │ duration0 == 0
       ▼
┌─────────────┐
│ PER_SECOND  │ ← 2-й полупериод
│   (2)       │   brightness1, duration1
└──────┬──────┘
       │ duration1 == 0
       ▼
┌─────────────┐
│   PER_END   │ ← Конец цикла
│   (3)       │
└──────┬──────┘
       │ count == 0 → PER_NEXT
       │ count > 0  → PER_FIRST
       ▼
┌─────────────┐
│  PER_NEXT   │ ← Пора загружать новую команду
│   (4)       │
└─────────────┘

9. Краткая шпаргалка

// Красный: 1 повтор, полная яркость 1 тик, выкл 1 тик
#define CMD_RED_ONCE  (0b00000000000000000000000000100001)

// Зелёный: бесконечно, полная яркость 2 тика, выкл 1 тик  
#define CMD_GRN_CYCLE (0b00000000000000000000000001010010)

// Оба: 3 повтора, RED ярко 1 тик, GRN ярко 1 тик, выкл 1 тик
#define CMD_BOTH      (0b00000000000000000000000001100011)
