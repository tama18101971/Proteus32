# Plan: Удаление мёртвого кода из aux_leds

Цель: удалить неиспользуемый код из aux_leds.c и aux_leds.h. Массивы команд, логика обработки (handle_aux, handle_aux_cmd, handle_aux_array, start_aux_cmd, start_aux_array) — **не трогаем**.

### 2. Удаляемые #ifdef блоки

- `#ifdef USE_BATTIND` в `set_aux_count()` и `slot_batt_ind()` — `USE_BATTIND` нигде не определён
- `#ifdef USE_EX_AUX` в `start_exaux_voltage()` — `USE_EX_AUX` нигде не определён
- `#ifdef AUX_DEBUG` в `debug_cmd()` и вызове `debug_cmd()` — `AUX_DEBUG` нигде не определён

### 3. Удаляемые extern из aux_leds.h

Все `extern` переменные которые используются ТОЛЬКО внутри aux_leds.c — не должны быть в .h:

- `extern union AUX_Cmd_u aux_cmd_red/grn`
- `extern AUX_Ctr_t aux_ctl_red/grn`
- `extern union AUX_Cmd_u *p_red/grn`
- `extern bool EnableArrayProcessingRed/Grn/Hbl`
- `extern const uint32_t *current_buf_red/grn/hbl`
- `extern const uint32_t buf_red[]/buf_grn[]/buf_sos_red[]`

**Оставляем extern** для `vwarning`, `vwarning_old` (используются в button.c).

### 4. Удаляемые defines из aux_leds.h

- `SHORT_BLINK` — закомментирован, нигде не используется
- `INFO_RED`, `INFO_GRN`, `ERRO_RED` — используются только в мёртвых функциях

### 5. Удаляемые комментарии/includes

- `aux_leds.c`: закомментированные `#include "eeprom.h"`, `"soft_start.h"`, `"macros.h"`, `"adc.h"`
- `aux_leds.c`: `#include "button_gpio.h"` — уже включается через `aux_leds.h`

### 6. Удаляемые переменные

- `aux_cmd_hbl` (буфер для HBL) — не используется
- `p_hbl` (указатель для HBL) — не используется

### 7. Комментарии для обновления

В `aux_leds.c` обновить шапку файла — убрать упоминания удалённых функций из документации.
