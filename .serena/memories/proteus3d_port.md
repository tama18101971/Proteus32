# Proteus3D — AVR-порт Proteus32 (синхронизация)

C:\Sonet5\Proteus3D — порт Proteus32 (CH32V003) на ATtiny1634 (AVR, 1 МГц, 16 КБ Flash / 1 КБ RAM, PlatformIO env attiny1634, bare-metal).

## Точка синхронизации
- Порт изначально снят с рабочего дерева, включавшего изменения коммита Proteus32 `2037f59` (батарейка-защита с храповиком).
- 2026-08-30: перенесена ВСЯ логика Proteus32 после `2037f59` (вплоть до `c26b30d`): единый потолок UI1/UI2 (ratchet = get_stepi(volt_max_mode)), ERRO_RED при клампах напряжения, турбо-память (ps.use_prev && ps.start), down_forever = menu_entry_flash(1,2000,RED), ex_lvls 3.4/3.2/3.0 В, API aux без параметра enable, немедленный старт стробов/массивов (WDT_IMMEDIATELY), ON_POWER() в start_aux_strobe, guard !EnableArrayProcessing у OFF_POWER, тайминги индикации счёта (152/448 мс), exaux ON 100 мс + старт WDTO_1S, опрос 30 Гц при любом активном драйвере.
- Намеренно НЕ переносится: `ae4c224` (сон без WDT уже нативен на AVR), AWU/LSI-специфика CH32, `d07848d` (ui_table дескрипторы — размерная оптимизация CH32).
- Отличия доменов: напряжение в bandgap-кодах (числитель 1126400 vs 1228800), AUX-тайминги кодами WDTO (0..15) вместо psc/win, поле count 5 бит (0..31), EEPROM своя (myeeprom.c, struct eeblock) вместо WL_FLASH/Option Bytes.
- UI-действия живут в src/button.c (не ui.c), main loop — src/proteus.c.
- Сборка: `pio run` (C:\Sonet5\Proteus3D); Flash 13896/16384 (84.8%), RAM 216/1024. Фичи-флаги в include/macros.h (USE_STROBE/MENU/BATTIND/EX_AUX/BLOCK/MAGIC_SLOTS, REAL_OFFPOWER — все включены).

## Актуальная дельта изменений Proteus32 для переноса в Proteus3D (2026-11-03)
При следующей синхронизации Proteus3D портировать следующие исправления логики:
1. **Кламп вместо установки яркости в каскаде защиты (`8170ffd`):**
   Шаг каскада напряжения вниз должен только декрементировать `mode_current`/`volt_stop_mode`. Безусловный `set_current(get_stepi(mode_current))` в каскаде приводил к паразитной вспышке (росту яркости) при разряде АКБ в UI1, если пользователь сам находился ниже нового потолка. Применение потолка выполняют 30-Гц клампы.
2. **Разделение сброса серий и потолка при сбое АЦП (`6d4a367`):**
   При ошибке измерения АЦП (`!voltage_ok`) сбрасывать только серии подтверждений (`reset_voltage_streaks`), сохраняя действующий защитный потолок `volt_stop_mode`. Сброс потолка в TURBO (`reset_voltage_latches`) выполнять только при отключении драйвера (`off_driver()`).
3. **Пауза рампинга в UI1 (`6d4a367`):**
   Пауза удержания кнопки на экстремумах рампинга увеличена до 750 мс (120 тиков при 160 Гц) вместо 500 мс.
4. **Гашение красного LED перед вечным сном (`b207afe`):**
   В `down_forever()` после 2-секундной аварийной индикационной вспышки гарантированно обесточивать светодиод (`off_red()`) перед входом в вечный сон, чтобы исключить тление и утечку тока через подтяжки/состояние пинов.
