1. Обзор системы

Модуль aux_leds управляет вспомогательными LED (красный/зелёный) через функцию handle_aux().

Два режима работы:

  • Одиночная команда (start_aux_cmd) — одно мигание с заданными параметрами
  • Массив команд (start_aux_array) — последовательность команд из Flash
// main.c — главный цикл
while (1) {
    if (mode == MODE_BEACON) {
        ntc_read();
        handle_aux();          // обработка AUX LED (задаёт интервал AWU)
        scan_ui1();
        ss_scan();
        AWU_Sleep_Now();       // MCU спит до следующего события AWU
    }
}
Ключевое: Тайминг задаётся параметрами AWU (prescaler + window) в самой команде.
Время полупериода = (psc_значение × win) / 128000 секунд.
MCU спит в STANDBY между полупериодами — энергопотребление ~2-5 мкА.

3. Структуры данных

3.1 Каналы LED (LED_Bits_t)

КонстантаЗначениеОписание
RED_LED0b001 (1)Красный LED
GRN_LED0b010 (2)Зелёный LED
HBL_LED0b100 (4)Подсветка
RED + GRN0b011 (3)Оба одновременно

3.2 Этапы автомата (PER_Step_t)

ЭтапЗначениеДействие
PER_INIT0Загрузка count из команды → переход в PER_FIRST
PER_FIRST1Яркость0 + AWU per0 → MCU спит per0 → переход в PER_SECOND
PER_SECOND2Яркость1 + AWU per1 → MCU спит per1 → переход в PER_END
PER_END3Обработка счётчика → PER_FIRST (следующий цикл) или PER_NEXT
PER_NEXT4Команда завершена → загрузка следующей из массива

3.3 Системные команды массива (Array_Cmd_t)

КомандаЗначениеОписание
AC_STOP0x00000000Остановить обработку массива
AC_REP_ATSTART0x00000001Повторить с начала массива
AC_REP_ATSTEPS0x00000005Повторить с шагом (поле steps)

4. Пошаговый алгоритм

1 Запуск массива команд 
// Определяем массив и запускаем
start_aux_array(buf_sos_red);
// Внутри: определяет канал из 1-го элемента, сбрасывает состояние,
// устанавливает EnableArrayProcessing = true
2 handle_aux() вызывается из main loop 
// handle_aux() для каждого канала:
if (EnableArrayProcessing) {
    p = handle_aux_array(buf, &ctl);  // загружает команду из массива
    if (p == NULL) disable;           // AC_STOP — отключаем
    else handle_aux_cmd(p, &ctl);     // выполняем один переход автомата
} else if (p) {
    handle_aux_cmd(p, &ctl);          // одиночная команда
}
3 handle_aux_cmd() — один переход автомата 
// PER_INIT: загружаем count из команды
// PER_FIRST: устанавливаем яркость0, настраиваем AWU per0 → MCU спит
// PER_SECOND: устанавливаем яркость1, настраиваем AWU per1 → MCU спит
// PER_END: обрабатываем счётчик, запускаем следующий цикл
4 MCU спит в STANDBY 
// После handle_aux() main loop вызывает:
AWU_Sleep_Now();
// MCU засыпает на время, заданное AWU per0 или per1
// Просыпается по событию AWU → следующий вызов handle_aux()

5. Макрос MAKE_CMD

// Формирование 32-битной команды из параметров:
MAKE_CMD(device, cycle, count, psc0, win0, psc1, win1, brightness0, brightness1)

// Пример: красный, бесконечно, 100мс ON / 100мс OFF, ярко
MAKE_CMD(RED_LED, 0, 0, AWU_PSC_256, 50, AWU_PSC_256, 50, 1, 0)
// psc=1(256), win=50 → 256×50/128000 = 100мс
Формула времени: time_ms = (psc_значение × win) / 128
Где psc_значение = (psc_idx + 8) × 128, т.е. psc_idx=0 → 128, psc_idx=5 → 4096

6. Быстрый старт

6.1 Одиночная команда

// Красный мигает 5 раз: 100мс ON, 100мс OFF
start_aux_cmd(
    MAKE_CMD(RED_LED, 0, 5, AWU_PSC_256, 50, AWU_PSC_256, 50, 1, 0),
    true, IDM_OTHER
);

6.2 Массив команд

// SOS на красном: . . . — — — . . .
const uint32_t sos[] = {
    MAKE_CMD(RED_LED, 0, 0, AWU_PSC_256, 50, AWU_PSC_256, 50, 1, 0),  // S: 100мс ON, 100мс OFF
    MAKE_CMD(RED_LED, 0, 0, AWU_PSC_1024, 38, AWU_PSC_256, 50, 1, 0), // O: 304мс ON, 100мс OFF
    MAKE_CMD(RED_LED, 0, 0, AWU_PSC_256, 50, AWU_PSC_256, 50, 1, 0),  // S: 100мс ON, 100мс OFF
    MAKE_CMD(RED_LED, 0, 0, AWU_PSC_2048, 44, AWU_PSC_256, 50, 1, 0), // Пауза: 704мс OFF
    0x6  /* AC_REP_ATSTART — повторить с начала */
};
start_aux_array(sos);

7. Массивы команд

Массивы хранятся в Flash (const uint32_t[]). Каждый элемент — либо LED-команда (MAKE_CMD), либо системная команда (0=STOP, 1=REP_ATSTART).

buf_sos_redSOS на красном, зациклен5

8. Примеры

8.1 Beacon (бесконечное моргание)

// Красный: cycle=1 (бесконечно), ON 100мс, OFF 100мс
uint32_t cmd = MAKE_CMD(RED_LED, 1, 0, AWU_PSC_256, 50, AWU_PSC_256, 50, 1, 0);
start_aux_cmd(cmd, true, IDM_BEACON);

8.2 Предупреждение о напряжении

// Быстрое: ON 100мс, OFF 1900мс → ~2с周期
uint32_t cmd = MAKE_CMD(RED_LED, 0, 0, AWU_PSC_256, 50, AWU_PSC_4096, 60, 1, 0);
start_aux_cmd(cmd, true, IDM_VWARNING);

8.3 Два независимых канала

// Красный быстро, зелёный медленно — параллельно
const uint32_t red[] = { MAKE_CMD(RED_LED, 0, 0, AWU_PSC_256, 25, AWU_PSC_256, 25, 1, 0), 0x6 };
const uint32_t grn[] = { MAKE_CMD(GRN_LED, 0, 0, AWU_PSC_2048, 32, AWU_PSC_2048, 32, 1, 0), 0x6 };
start_aux_array(red);
start_aux_array(grn);  // оба работают параллельно

9. Диагностика

LED не моргает

ПроверкаКак
enable == 1?EE_PRINTF("en=%d\n", ctl.enable);
period != PER_NEXT?PER_NEXT = команда завершена, нужна новая
device != 0?Проверить биты 0..2 команды
brightness0 != 0?Яркость должна быть > 0

Моргает неправильно

ПроблемаПричинаРешение
Слишком быстроpsc/win малыУвеличить psc и/или win
Не зацикливаетсяAC_REP_ATSTART нетДобавить 0x6 в конец массива
Останавливаетсяcount исчерпанУвеличить count или cycle=0
Готово! Ключевые моменты:
  • Тайминг задаётся AWU prescaler + window (а не тиками ×15мс)
  • MCU спит в STANDBY — энергопотребление ~2-5 мкА
  • MAKE_CMD(device, cycle, count, psc0, win0, psc1, win1, brightness0, brightness1)
  • handle_aux() обрабатывает ОДИН переход автомата за вызов
