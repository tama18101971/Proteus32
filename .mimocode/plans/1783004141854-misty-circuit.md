# Fix: out_set_stc показывает out=4102 при step=511

## Проблема
`out_set_stc` вычисляет `out = getBright_CRT_9to12Bit(step) + get_min_level(step)`. При step=511 CRT возвращает 4095, `get_min_level` добавляет минимум 5 → out=4102. Лог показывает 4102, хотя DAC клэмпит до 4095 в `dac7571_set_voltage`.

Закомментированный clamp (ui.c:141):
```c
//if (out > 4095) out = 4095;  // не удалять, блин - надо! С новым I2C не надо
```

## Решение

Вернуть clamp в `out_set_stc` (ui.c:141):

```c
if (out > 4095) out = 4095;
```

Лог будет показывать корректное значение, и отпадёт необходимость в клэмпе на уровне DAC.

## Файлы
- `src/ui.c:141` — раскомментировать / записать clamp

## Верификация
`pio run` — сборка. Проверить по логу: при step=511 должно быть out=4095.
