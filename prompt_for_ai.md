# Промт для генерации кода битовых полей handle_aux()

## Контекст проекта
Проект Proteus003 для микроконтроллера CH32V003 (RISC-V, 16KB Flash, 2KB RAM). 
Управление вспомогательными LED-индикаторами (красный/зелёный) через функцию `handle_aux()`.

---

## Описание битовых полей

### 1. Команда AWU_Cmd_u (32 бита)
Это основная структура для задания параметров моргания LED.

#### Режим aux (управление LED):
```
Биты 0..2   : device      — Каким LED управляем
              001 = RED_LED (красный)
              010 = GRN_LED (зелёный)  
              100 = HBL_LED (подсветка)
              Можно комбинировать: 011 = RED+GRN

Бит 3       : cycle       — Зацикленность
              0 = зациклено (бесконечно)
              1 = без цикла (однократно)

Биты 4..7   : count       — Количество повторов (0..15)
              0 = бесконечный цикл (если cycle=0)
              1..15 = заданное число повторов

Биты 8..16  : duration0   — Длительность 1-го полупериода (9 бит, 0..511)
              Измеряется в количестве повторов по ~15мс (handle_aux() вызывается каждые 15мс)
              Пример: duration0=5 → 5×15мс = 75мс

Биты 17..25 : duration1   — Длительность 2-го полупериода (9 бит, 0..511)

Биты 26..28 : brightness0 — Яркость 1-го полупериода (3 бита)
              0 = выключен
              1 = полная яркость
              2 = слабая (подсветка)

Биты 29..31 : brightness1 — Яркость 2-го полупериода (3 бита)
```

#### Режим cmd (команда обработчика массива):
```
Биты 0..1   : command     — Команда обработчика
              0 = AC_STOP (остановить)
              1 = AC_REP_ATSTART (повтор с начала массива)
              2 = AC_REP_ATSTEPS (повтор с шагом)

Биты 2..4   : steps       — Шаг зацикливания (0..7)

Биты 5..31  : is_cmd      — Если ВСЕ 27 бит == 0, это системная команда
              Иначе — это параметры LED
```

### 2. Контрольная структура AWU_Ctr_t (32 бита)
Внутреннее состояние каждого LED-канала.

```
Бит 0       : enable              — 1 = обработка активна

Биты 1..3   : period              — Текущий этап (0..4)
              0 = PER_INIT (инициализация)
              1 = PER_FIRST (1-й полупериод)
              2 = PER_SECOND (2-й полупериод)
              3 = PER_END (конец цикла)
              4 = PER_NEXT (нужна новая команда)

Биты 4..6   : current_brightness  — Текущая яркость (для сравнения)

Биты 7..15  : work_duration       — Оставшаяся длительность (9 бит)

Биты 16..17 : idmode              — Режим индикации
              0 = IDM_OTHER
              1 = IDM_BEACON
              2 = IDM_VWARNING
              3 = IDM_STROBE

Биты 18..21 : arr_index           — Индекс в массиве команд (0..15)

Биты 22..25 : work_count          — Оставшиеся повторы (0..15)

Биты 26..31 : reserved            — Резерв (не используется)
```

### 3. Формула вычисления команды
```c
// Формирование 32-битного кода:
// duration в единицах по ~15мс (0=0мс, 1=15мс, 2=30мс, 5=75мс, 10=150мс)
uint32_t cmd = device | (cycle << 3) | (count << 4) | 
               (duration0 << 8) | (duration1 << 17) | 
               (brightness0 << 26) | (brightness1 << 29);

// Или через побитовые операции:
cmd |= (value << start_bit);   // установить поле
cmd &= ~(mask << start_bit);   // сбросить поле
cmd |= (new_value << start_bit); // записать значение
```

### 4. Алгоритм работы handle_aux()
```
1. Проверяем EnableArrayProcessingRed / EnableArrayProcessingGrn
2. Если включено — обрабатываем массивы команд:
   - handle_aux_array() — извлекает команду из массива
   - Если команда == 0 — это системная команда (STOP/REP_ATSTART/REP_ATSTEPS)
   - Иначе — переходим к следующему элементу массива
3. Если handle_aux_array() вернул NULL (AC_STOP) — выключаем соответствующий флаг
4. handle_aux_cmd() — выполняет команду:
   - PER_INIT: загружаем duration0, count, переходим в PER_FIRST
   - PER_FIRST: устанавливаем brightness0, уменьшаем duration0
   - Когда duration0 == 0 → PER_SECOND
   - PER_SECOND: устанавливаем brightness1, уменьшаем duration1
   - Когда duration1 == 0 → PER_END
   - PER_END: уменьшаем count, если count == 0 → PER_NEXT
   - PER_NEXT: пора загружать новую команду

Примечание: handle_aux() вызывается каждые 15мс (Delay_Ms(15) в main.c)
```

### 5. Примеры использования
```c
// Моргание красным: 1 повтор, 1 тик ЯРКО → 1 тик ВЫКЛ
#define CMD_RED_ONCE  0b00000000000000000000000000100001

// Моргание зелёным: бесконечно, 2 тика ЯРКО → 1 тик ВЫКЛ
#define CMD_GRN_CYCLE 0b00000000000000000000000001010010

// Beacon: программируемый тип и режим
uint32_t beacon_cmd = 0b00000000000000010000000100001000 
                      | beacon_type 
                      | ((beacon_mode + 7) << 12);
```

### 6. Массивы команд
```c
// Красный LED: 5 команд для SOS-паттерна
const uint32_t buf_red[5] = {
    0b101000000000000010001010001,  // ...
    0b100010100000000010001010001,  // ---
    0b101000000000000010001000001,  // ...
    0b100010100000000010001010001,  // ---
    0x6                               // AC_STOP
};

// Зелёный LED: 3 команды
const uint32_t buf_grn[3] = {
    0b101000000000000010001011010,  // ...
    0b100010100000000010001011010,  // ---
    0                                 // AC_STOP
};
```

## Задача для ИИ

**На основе описания выше, создай:**
1. Новую 32-битную команду для моргания с нужными параметрами
2. Функцию, которая формирует команду программно
3. Код для запуска обработки через handle_aux()

**Формат ответа:**
```c
// Описание назначения команды
#define MY_CMD 0bXXXXX...  // или вычислить программно

// Функция формирования команды
uint32_t make_my_command(params...) {
    uint32_t cmd = 0;
    // ... вычисление
    return cmd;
}

// Запуск обработки
void start_my_led(void) {
    uint32_t cmd = make_my_command(...);
    start_aux_cmd(cmd, AWU_60MS, true, IDM_OTHER);
}
```
