# Fix: anti-windup проверяет ДО обновления integral

## Проблема

Из лога: E=5, I растёт от 7604 до 7968, L застрял на 200. Integrator бесконечно копится.

Корень: `output_signed` вычисляется из ТЕКУЩЕГО integral (строки 221-224), а проверка `output_signed < max_limit` (строка 244) происходит ДО добавления delta_i. После добавления I_term может превысить max_limit.

## Решение

Проверять anti-windup на основе **нового** integral, а не текущего:

```c
// Вычисляем что БУДЕТ после интегрирования
int32_t new_integral = s->integral + delta_i;
int32_t new_I_term = tl_div_round(new_integral * Ki, 256);
int32_t new_output = P_term + new_I_term;

// Не накапливать если новый выход насыщен
if (new_output <= cfg->max_limit) {
    s->integral = new_integral;
}
```
