# Анализ: Ожидание освобождения I2C шины

## Проблема

В текущем I2C драйвере (`src/i2c.c`) не все функции гарантируют освобождение шины перед следующей операцией:

| Функция | Ждёт BUSY=0? | Проблема |
|---------|-------------|----------|
| `i2c_start()` | Да (перед START) | OK |
| `i2c_stop()` | Да (после STOP) | OK |
| `i2c_send_addr()` | **Нет** (при NACK) | Генерирует STOP, но не ждёт освобождения шины |
| `i2c_send_byte()` | Нет | Ожидает TXE, но не проверяет BUSY |
| `i2c_wait_ack()` | Нет | Возвращает ошибку, но не генерирует STOP и не ждёт BUSY |

**Сценарий ошибки:** `i2c_send_addr()` получает NACK → генерирует STOP → следующий `i2c_start()` находит шину занятой (BUSY=1) → зависание или потеря данных.

---

## Решение

### 1. Добавить функцию `i2c_wait_bus_free()`

```c
// В i2c.h
void i2c_wait_bus_free(void);  // Ожидание освобождения шины I2C

// В i2c.c
void i2c_wait_bus_free(void) {
    uint32_t timeout = 100000;
    while (I2C1->STAR2 & I2C_STAR2_BUSY) {
        if (--timeout == 0) return;
    }
}
```

### 2. Исправить `i2c_send_addr()` — ждать BUSY=0 после NACK

```c
void i2c_send_addr(uint8_t addr, uint8_t direction) {
    I2C1->DATAR = (addr << 1) | (direction & 0x01);
    uint32_t timeout = 100000;
    while (!(I2C1->STAR1 & I2C_STAR1_ADDR)) {
        if (I2C1->STAR1 & I2C_STAR1_AF) {
            I2C1->STAR1 &= ~I2C_STAR1_AF;
            I2C1->CTLR1 |= I2C_CTLR1_STOP;
            i2c_wait_bus_free();  // ← ДОБАВЛЕНО
            return;
        }
        if (--timeout == 0) return;
    }
    (void)I2C1->STAR1;
    (void)I2C1->STAR2;
}
```

### 3. Исправить `i2c_wait_ack()` — генерировать STOP при NACK

```c
uint8_t i2c_wait_ack(void) {
    uint32_t timeout = 10000;
    while (!(I2C1->STAR1 & (I2C_STAR1_TXE | I2C_STAR1_AF))) {
        if (--timeout == 0) return 1;
    }
    if (I2C1->STAR1 & I2C_STAR1_AF) {
        I2C1->STAR1 &= ~I2C_STAR1_AF;
        I2C1->CTLR1 |= I2C_CTLR1_STOP;  // ← ДОБАВЛЕНО: генерируем STOP
        i2c_wait_bus_free();              // ← ДОБАВЛЕНО: ждём освобождения
        return 1;
    }
    return 0;
}
```
