# Fix: multiple definition of `raw_temperature_adc`

## Проблема
Линкер выдаёт ошибку `multiple definition of raw_temperature_adc`:
- `adc.c:33` — `uint16_t raw_temperature_adc = 0;` (основное определение, сюда пишет `adc_read()`)
- `main.c:38` — `uint16_t raw_temperature_adc = 271;` (дублирующее определение)

## Решение

**Единственное изменение** в `src/main.c:38`:

```c
// Было:
uint16_t raw_temperature_adc = 271; // 25°C

// Стало:
extern uint16_t raw_temperature_adc; // определена в adc.c
```

## Верификация
`pio run` — сборка без ошибок линковки.
